# Week 1 - VM vs Container

## 학습 내용

- Virtual Machine과 Container의 차이
- Hypervisor와 Container Runtime
- Docker 기본 구조
- Image와 Container의 차이
- Docker Desktop 환경 구축

## 핵심 개념

Docker Image는 Container를 생성하기 위한 템플릿이고,
Docker Container는 Image를 기반으로 실제 실행되는 인스턴스이다.

## 기본 명령어

docker --version
docker images
docker ps
docker ps -a
docker run hello-world
